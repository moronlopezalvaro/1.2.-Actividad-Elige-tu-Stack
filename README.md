# 1.2.-Actividad-Elige-tu-Stack

## ¿Qué he hecho en este proyecto?

En esta actividad he estado investigando y sentando las bases teóricas y prácticas para elegir nuestro entorno de desarrollo web. Principalmente he trabajado en dos cosas:

1. **[Informe de Consultoría](Informe_Consultoria.md)**: He redactado un informe analizando cómo funciona la arquitectura web básica. He hablado de las diferencias entre la parte del cliente y del servidor, qué diferencia hay entre una web estática y una dinámica, y cómo funciona la infraestructura por debajo (servidores web, PHP-FPM, etc.). Finalmente he justificado mi elección de herramientas para el stack: **PHP** con el framework **Laravel 12** por su patrón MVC, la seguridad que aporta y lo bien organizado que está.

2. **[Fichero de demostración PHP](fichero_demostracion.php)**: He creado un pequeño script en PHP que muestra una página web dinámica básica. Simplemente obtiene la fecha y la hora actual del servidor mediante código PHP y lo incrusta en el HTML, para demostrar en la práctica cómo el servidor procesa información antes de mandársela al cliente.
